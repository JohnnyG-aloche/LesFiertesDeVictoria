# Les fiertés de Victoria
Application Android hors connexion avec deux compteurs : 💎 Diamants et 💩 Cacas. Les quantités sont sauvegardées automatiquement sur le téléphone.

GitHub Actions compile l'APK à chaque push sur `main`, ou manuellement depuis l'onglet Actions. L'APK est disponible dans l'artefact `Les-fiertes-de-Victoria-APK`.
